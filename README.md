# 판서 (Panseo)

와콤 펜·전자칠판 터치로 화면 위에 바로 쓰는 Windows 판서 프로그램입니다.
수업 화면(PPT, PDF, 웹페이지, 동영상) 위에 필기하고, 움직이는 화면을 확대한 채로 필기할 수 있습니다.

## 설치

1. [Releases](https://github.com/cos2104/panseo/releases/latest)에서 `Panseo.exe`를 내려받습니다.
2. 원하는 폴더(예: 바탕화면)에 두고 실행합니다. 설치 과정은 없고, Windows 10/11에 기본으로 들어 있는 .NET Framework 4.8로 동작합니다.
3. 새 버전이 나오면 도구 모음 제목 줄에 **⬇ 업데이트** 버튼이 나타납니다. 누르면 새 버전을 받아 다시 실행합니다.

## 주요 기능

- **펜 · 형광펜 · 텍스트 · 도형**(직선, 화살표, 네모, 동그라미) — 와콤 필압 지원
- **지우개** — 획 지우개, 부분 지우개(실제 범위 표시), 와콤 펜 뒤쪽 지우개
- **배경** — 화면 위(투명), 흰판, 칠판
- **라이브 확대** — 고른 영역을 실시간으로 확대한 채 필기. Zoom 등 화면 공유에도 확대된 화면이 보입니다
- **스크롤 따라가기 (실험)** — PDF·웹페이지를 스크롤하면 판서가 함께 움직입니다
- **커서 모양** — 연필 · 점(실제 굵기·색 그대로) · 십자, 크기 0.5~2배
- **필기 숨기기**, 되돌리기 / 다시 실행, 화면 저장(사진\판서 폴더)
- **판서할 화면 선택** — 와콤·전자칠판(터치) 화면을 자동으로 찾고, 직접 고를 수도 있습니다
- **단축키 설정** — ⚙ 버튼에서 기능마다 키를 지정. '어디서나'를 켜면 다른 프로그램을 쓰는 중에도 동작

## Stream Deck 플러그인

판서의 도구·색·배경·확대 등을 Stream Deck 버튼으로 조작합니다. 지금 쓰는 도구·색, 확대 배율, 굵기가 버튼에 표시됩니다(Stream Deck 6.4 이상).

- 판서의 ⚙ 설정 창에서 **Stream Deck 플러그인 설치**를 누르거나, [Releases](https://github.com/cos2104/panseo/releases/latest)에서 `com.cos2104.panseo.streamDeckPlugin`을 내려받아 더블클릭합니다.
- Stream Deck 앱의 동작 목록에서 **판서** 묶음의 버튼을 끌어다 놓습니다. 색·도형·배경 버튼은 속성 창에서 고릅니다.
- 판서가 꺼져 있을 때 버튼을 누르면 판서를 켭니다.
- 플러그인 소스는 `streamdeck/` 폴더(`build.bat`로 빌드)에 있습니다.

## 인증키 (이 저장소는 비공개, 배포는 공개 저장소 cos2104/panseo 릴리스)

- 처음 실행하면 PC 번호(MachineGuid 해시 16자)가 나오고, 그 PC용 인증키를 넣어야 실행됩니다. 키는 `settings.ini`의 `license=`에 저장됩니다.
- 키는 `keygen\PanseoKey.exe`(PC 번호·이름 → 만들기 → 복사)로 만듭니다. 만든 키는 `keygen\issued.txt`에 쌓입니다.
- `keygen\private.key`는 비밀키입니다. 저장소에 올리지 않으며(.gitignore), 잃어버리면 새 키를 만들 수 없으니 따로 백업해 둡니다.

## 직접 빌드하기

`build.bat`를 실행하면 Windows에 들어 있는 C# 컴파일러로 `Panseo.exe`를 만듭니다. 별도 설치가 필요 없습니다.
